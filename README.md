رادار الأردوينو الذكي 📡
مشروع هندسي يهدف إلى بناء نظام رادار متكامل باستخدام لوحة Arduino Uno وحساس الموجات فوق الصوتية (HC-SR04). يقوم النظام بمسح المنطقة المحيطة بزاوية 180 درجة للكشف عن الأجسام وتحديد مكانها بدقة.
🌟 مميزات المشروع:
مسح شامل: يدور الحساس آلياً لتغطية مساحة واسعة.
تنبيهات ذكية: نظام ألوان (أخضر، أصفر، أحمر) مع صوت إنذار يتغير حسب قرب الجسم.
عرض مرئي: واجهة رسومية على الكمبيوتر تعرض الأجسام المكتشفة كأنها رادار حقيقي.
أمان متطور: يتضمن خاصية "عداد الاختراق" لتسجيل التحركات المشبوهة.
🛠️ المكونات الأساسية:
Arduino Uno (المخ المدبر).
Ultrasonic Sensor (العين التي ترى المسافات).
Servo Motor (المحرك المسؤول عن الدوران).
LEDs & Buzzer (للتنبيهات الضوئية والصوتية).
فكرة المشروع: دمج الهاردوير مع السوفتوير لتقديم حل أمني بسيط وفعال لمراقبة الأماكن وتجنب الاصطدامات.
